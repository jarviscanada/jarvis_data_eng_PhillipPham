# Introduction
This program is a text-based student registration system that manages an indexed file of students to organize which courses students are enrolled in and their information.

There are 8 main functions: initializing the student list; adding, updating, and deleting students; querying; and generating a report of courses for students.

This program was written entirely in COBOL for file manipulation, processing, data querying, and interactivity. GNU COBOL was used to  compile, and OpenCobolIDE was used to develop.

# Quick Start
Install GNU COBOL or another COBOL compiler to compile the code with the following command from the project root folder.
```
cobc -x STUDENT-REG.cbl -o STUDENT-REG
```
Then run the compiled program in your desired terminal.
```
./STUDENT-REG
```
From there, the text-based menus should be able to interact with the rest of the program.

# Implementation
There are 4 main files that run this program:

* STUDENT-REG.cbl
    * The uncompiled COBOL code for manipulating and querying the data
* STUDENTINDEX.DAT
    * The main indexed VSAM file that is used for the student data
* STUDENTSEQUENTIAL.DAT
    * A sequential file that is used in the `GENERATE VSAM` function to load an initial batch of student data
* CLASSREPORT.DAT
    * A report file generated by the `REPORT FILE WITH COURSE BREAK` function to list courses alphabetically and their respective students' data

## Data
Each student record has the following data in the formats listed:

* ID
    * 4-digit numeric
    * Primary key (unique) for the index file
* STUDENT NAME
    * 25-character alphanumeric
* BIRTHDAY
    * 8-digit numeric
    * YYYYMMDD format
* COURSE
    * 15-character alphanumeric
* INSERT DATE
    * 8-digit numeric
    * YYYYMMDD format
* UPDATE DATE
    * 8-digit numeric
    * YYYYMMDD format

## Functions
There are 8 main functions that the program can run:

### 1 - Generate VSAM File
Reads the sequential file `STUDENTSEQUENTIAL.DAT` and converts the student records into a new indexed file.
A sample file is provided in the repository.
Note that if an indexed file already exists, this will overwrite it.

### 2 - Insert Student Data
Inserts a new student record into the index file with the student's name, birthday, and course given through the menu.

### 3 - Update Student Data
Updates an existing student record by ID with a new name, birthday, and course given through the menu.

### 4 - Delete Student Data
Deletes an existing student record with a given ID.

### 5 - Class Query (All Students)
Queries all students' data indexed by ID

### 6 - Query Student By ID
Takes a student ID and queries their data if the entry exists.

### 7 - Query By Date Of Inclusion
Queries all students that were inserted into the student index on a given date.

### 8 - Report File With Course Break
Generates a report file `CLASSREPORT.DAT` that lists courses in alphabetical order, along with their respective students' data.

# Improvement
## Structure
Currently, the initial version was developed in one large module, which helps with consistent file definitions and menu formatting. However, it would be more maintainable, less coupled, and easier for maintainers to pick up if it were split into smaller, more digestible subprograms.

## Testing
As this program was tested manually, a more thorough test suite would definitely ensure that the code has strong case coverage and that file operations are consistent.

## Error Handling
Stronger error handling for bad data and invalid files can definitely aid usability. Pre-validation can help filter bad data before it enters the database. Further, better error messaging and control flow can assist users in resolving file related issues without needing to know COBOL file status codes.
